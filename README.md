Kho này **chỉ chứa file cài đặt** (installer) của HP Action LIVE để ứng dụng
tự kiểm tra và tải bản cập nhật. **Không có mã nguồn** trong kho này.

- Mã nguồn: kho riêng (private) của HP Media.
- Mỗi bản phát hành gồm `HP-Action-LIVE-Setup-X.Y.Z.exe` và `latest.yml`.
- Ứng dụng đọc bản mới nhất qua GitHub Releases API.

Tải bản mới nhất: xem mục **Releases** bên phải.
